# 对齐相似 Prompt 的图表脚本结构

## Goal

让 ChartPilot/Goose 面对与 SY135 相同或语义相似的“按类别建立同群基准、按阈值分级、
用气泡图呈现风险”请求时，先选择与人工实践一致的可视化原型，再生成任务专用 Python；
对齐对象是脚本中的数据聚合、面板职责、图形编码和阈值表达，而不是像素级复刻 PNG。

## Background

- 人工 prompt 要求：为每个机号选出使用最多的档位，按档位计算平均油耗，找出高于
  同档均值 25%/50% 的机号，并用气泡图呈现。
- 人工 `process.py` 的绘图逻辑不是逐机号散点：上图按“档位 x 风险等级”绘制堆叠数量
  柱，下图按相同组合聚合平均油耗和机号数，用气泡、同档基准及 25%/50%/75% 阈值线
  表达风险，右侧说明统计口径。
- 当前仓库的 `agent/tests/fixtures/sy135_render.py` 已体现上述双图原型，但它只用于等价
  回归，没有成为真实 Agent 选择图表结构时可复用的决策依据。
- 最新真实 Goose 运行的数据口径正确，最终图片也可读，但其 `analysis_result.json` 把
  `visual_grain` 定义为“主图每个气泡一个机号”；对应 `generated_chart.py` 上图仅绘制
  11 个档位汇总气泡，下图绘制 96 个异常机号，脚本结构仍与人工实践不同。
- 现有 Skill 只把“population composition + aggregate metric/threshold panel”描述为可选
  建议，没有要求 Agent 先做图表原型匹配，也没有给出可执行的原型契约或脚本级验收。
- 既有产品约束继续有效：一个 Skill、两个 MCP 工具、三个可编辑 Python 模板、CSV-first、
  内置 WinPython、无确定性简单任务路由、无业务字段硬编码、Agent 可以自由修改代码。

## Requirements

- R1：逐项对照人工 `process.py`、人工 PNG、真实 Goose 的 `analysis_result.json`、
  `generated_chart.py` 和最终 PNG，记录脚本级结构差异及其上游原因。
- R2：建立基于分析意图和数据角色的图表原型选择机制，不按 SY135、档位、油耗或固定
  中文关键词硬编码路由。
- R3：为“分类构成 + 同群基准 + 分级阈值 + 气泡规模”这一类请求提供明确原型：上层
  表达人群/对象数量构成，下层表达聚合指标、规模、基准和阈值，附统计口径说明。
- R4：分析阶段必须把所选原型、面板职责、每个 mark 的聚合粒度、编码、排序、阈值和
  注释策略写入 `chart_intent`，render 阶段据此生成脚本，不得在 render 阶段另起一套叙事。
  这些字段是 Agent 的可审计计划，不扩展成由 MCP 执行的业务 DSL。
- R5：Skill 和模板应使 Agent 优先复用相似原型，但仍允许在 prompt 或数据形态不适合时
  说明理由并采用其他结构；不能把所有任务强制成 SY135 双图。
- R6：验收重点包含生成的 Python 源码及其声明的图表结构，不再只检查统计结果、PNG
  非空、双区域和人工看图。
- R7：至少使用一个匿名、不同字段名的合成请求证明原型选择依据是语义角色而非字段名，
  并保留一个不适合该原型的通用用例证明回退能力。
- R8：不得重新引入确定性业务工具、额外 Python 路由或中间 XLSX；现有运行时依赖足够
  时不新增依赖。
- R9：本次 MVP 只完整实现并验证“分类风险构成 + 聚合气泡 + 同群基准/阈值”原型；
  建立可扩展的选择与声明结构，但不交付没有人工基准支持的其他原型。

## Acceptance Criteria

- [x] AC1：任务研究记录完整说明人工与 Goose 脚本在聚合粒度、面板、mark、编码、阈值、
  注释和说明区上的对应关系。
- [x] AC2：相似意图可映射到一个具名但字段无关的图表原型，`chart_intent` 明确声明原型和
  各面板的输入粒度、聚合与编码。
- [x] AC3：使用原 prompt/CSV 的真实 Goose 前向测试生成的 Python 包含“分类风险构成”与
  “聚合气泡 + 基准/阈值”两个协同面板，不再以逐机号散点作为主要表达。
- [x] AC4：可复用 Skill、参考原型和三个模板不写死 SY135 字段名、11 个档位或 25%/50%
  数值；任务专用生成脚本可以具体化当前 prompt 明确给出的字段映射、类别和阈值。
- [x] AC5：匿名改字段合成用例仍采用同一原型；普通单指标比较用例不被错误套用该原型。
- [x] AC6：新增脚本级回归断言，并继续通过 Skill、模板、MCP、运行时和 Agent 测试。
- [x] AC7：最终图中文可读、无重叠/裁切，且 Agent 实际读取图片；视觉验收作为脚本结构
  正确后的第二道门禁。
- [x] AC8：产品仍只暴露一个 Skill、两个 MCP 工具和三个可编辑 Python 模板，无新增依赖。

## Out Of Scope

- 像素级复制人工 PNG、强制使用 PIL 或复刻人工脚本的 Excel 输出。
- 在本次任务中一次性设计覆盖所有 CSV 场景的大型可视化 DSL 或确定性图表引擎。
- 发布 ZIP 在中文和空格路径下的搬移验证。
